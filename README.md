# DevOS AI

🚀 The open-source AI operating system for developers.

DevOS AI helps developers understand codebases, review pull requests, debug errors, and automate developer workflows using AI.

---

## Features

• Chat with any GitHub repository
• AI code review for pull requests
• Debug stack traces instantly
• Generate unit tests automatically
• Local LLM support (Ollama, Mistral, DeepSeek)
• CLI + Web dashboard

---

## Architecture

DevOS AI combines:

* vector search
* LLM agents
* repo analysis
* developer automation
